# FarmSetupGoal

## Purpose

Builds and repairs the persistent farm plan before crop operations run.

## Phases

- `GATHER_LOGS`: retain enough wood for the rolled perimeter, gate, and bootstrap crafting.
- `GATHER_STONE`: gather two stone for farming tool progression.
- `CLEAR`: remove safe surface/headroom obstructions.
- `WATER`: clear the owned irrigation cell and empty the starter water bucket into it.
- `FENCE`: craft/place the derived perimeter.
- `GATE`: craft/place one open gate in the intentional perimeter opening. Its axis follows exterior-to-interior travel and every required lateral neighbor is an owned fence.
- `TILL`: equip a hoe and till owned crop cells.
- `READY`: repair missing infrastructure and clear new safe obstructions.

Missing or fluid-filled owned ground (including a damaged entrance path, but never the planned water cell) is repaired before tilling or crop work. The NPC consumes one carried hoe-compatible dirt block and places it from an exact reachable non-colliding stand through `PlacingBlockAi`. A successful crop-ground repair immediately persists the plan back to `TILL`, preventing a same-priority crop goal from seeing `READY` before the later maintenance scan. Coarse/rooted repair items are normalized to ordinary dirt so the existing hoe action reaches farmland in one successful interaction. The goal then approaches an exact till stand, equips or waits for the shared crafting path to provide a hoe, and emits one renderer-appropriate hand action only when tilling succeeds. Repaired entrance-path/non-crop ground remains untilled. If no repair material remains, setup performs a bounded twelve-path-check surface search for external dirt/grass, never mining its own farm or home/build footprint. Existing crops, healthy path ground, irrigation, fences, and the gate are not overwritten.

The goal uses `ClearBlockAi`/`BreakingBlockAi` for obstruction removal and always validates the blocker actually hit by the current break ray, not only the originally requested surface obstruction. It retains both positions as one request context and cools both when a real clear/approach failure occurs, so a protected ray blocker cannot restart the same request forever. When that ray first hits protected farm ground, the NPC does not break it: it selects an exactly reachable stand whose centered eye ray first hits the original obstruction, walks to the center of that stand, and reselects the original clear request. Interior maintenance approach uses the farm interaction-stand rule, which accepts farmland's non-full collision support; the generic clear helper's full-solid stand rule is intentionally not used for this staging step. Requests cool down only when no safe clear-ray stand/path exists or the bounded approach/clear genuinely fails.

A maintenance-clear approach keeps one bounded episode timer across stand reselection. Reaching a stand whose live ray still resolves to a protected or otherwise disallowed blocker records that logical stand as failed; it cannot be selected again during the episode. The next stand comes from at most twelve exact path checks and must have a centered-eye ray whose first hit passes the same farm-clear safety validation. Only transition into a real `CLEAR` action resets the action timer. If no different safe stand exists, or the 25-second episode expires, setup cools the requested/resolved blocks and hands off to the existing bounded local forced-rise recovery instead of recreating `APPROACH_FARM_WORK` at the current cell.

A valid closed owned gate is opened before ground repair, maintenance obstruction selection, or phase-specific work, including while the persisted phase is still `GATE` or `TILL`. This ordering is an invariant: interior foliage must not receive a clear cooldown merely because the later `READY` switch has not yet opened the perimeter. Successfully opening the gate clears prior obstruction retry entries because the route topology has changed.

Farm approach arrival is based on the exact centered X/Z stand plus grounded physical Y occupancy, not raw `blockPosition()` equality. A logical navigation stand is the air cell above its support, but farmland is 15/16 block high: a correctly arrived NPC can therefore report `blockPosition() == stand.below()` while its physical feet are only 1/16 block below the logical Y. This normalized arrival is used by maintenance-clear handoff, placement recovery, and ordinary setup interactions. It does not accept adjacent X/Z cells or a worker one full block below. Once maintenance approach reaches this normalized stand, the setup goal reselects the intentional obstruction and starts its owned-farm-authorized `ClearBlockAi`; generic return-route clearing remains forbidden from destroying protected farm blocks.

Not every visible dirt/grass cell is unfinished crop soil. `Plan.pathPositions()` is the intentional entrance-to-water walking lane and remains ordinary tillable ground; it is excluded from `cropGroundPositions()`. Dirt/grass in a crop-ground cell is returned by `findUntilledGround()` and tilled after higher-order maintenance is clear. A sapling occupying planned crop space or its required headroom is a safe maintenance obstruction and must be removed before that till/plant progression continues.

If an older claimed farm has no reachable entrance, setup first searches the bounded farm/entrance route for a safe clear target. When the entrance is above the NPC it requests the higher-priority forced upward/pillar escape goal and yields. Otherwise it retains ownership and runs a 25-second `ReturnPositionAi` reacquisition episode with local-route navigation and safe route clearing; `PathStuckFallbackAi` is disabled for this return. A same/lower failed episode requests a short local forced rise. Only completed failed episodes consume the recovery budget. After that bounded budget it may replace only an unfinished plan with no placed water, fence/gate, farmland, or crop; READY and materially started farms are retained.

The goal protects home/build blocks, irrigation, expected perimeter blocks, and crops. Generic destruction is denied centrally by `FarmAi.isOwnedFarmDestructionProtected(...)` at `BreakingBlockAi`/`PlayerNpcBlockBreakUtil`, including every block below the farm's buffered footprint. Only this goal's revalidated maintenance clear and `FarmCropGoal`'s mature harvest/forage paths opt into owned-farm destruction. A legacy gate saved inside the farm is migrated to the correct perimeter opening. A gate on a fence/crop/path cell is cleared as an owned obstruction; an old gate at the correct opening with the wrong axis is rotated/opened in place after support and lateral fences are validated.

Fence, gate, irrigation, till, and gate-use actions select an exact reachable stand inside the real 3.75-block interaction radius. The current occupied feet position is accepted whenever it is already inside that radius; the six-block `ClearBlockAi` reach must never be used as placement reach. Candidate geometry covers the full three-block horizontal ring and one block of vertical slope, including diagonal and lower exterior stands. If no exact path currently reaches a placement-capable stand, setup preserves both the requested placement and one target-adjacent final stand. `ReturnPositionAi` works toward that same final stand through the gate, clearing only validated route blocks and requesting shared upward/pillar recovery only after a bounded failure. If no final stand is visible from the NPC's current region, it performs one bounded entry recovery and resolves the final stand there; it never alternates unrelated perimeter staging positions. Blocker traces include phase, target, and the missing-stand reason before a retry is cooled.

Placement and tilling delays are animation-free. Only a successful fence, gate, water, or tilled-soil world mutation emits feedback: exactly one normal NPC use swing or one dedicated non-repeating Epic Fight use animation. Failed validation or placement emits neither. Placement sound remains tied to the same successful commit.

`READY` maintenance exposes a shared strict crop-work predicate. Irrigation, fence/gate, path support, and every unoccupied crop-ground cell must still be valid, with exposed crop cells specifically required to be farmland. Dirt/grass support deterministically rewinds the saved plan to `TILL` and records `farm READY rewound to TILL`; repaired crop ground already persists the same rewind at the repair commit. A crop currently occupying the cell is preserved until harvest, after which the exposed support is checked on the next scheduler pass.
